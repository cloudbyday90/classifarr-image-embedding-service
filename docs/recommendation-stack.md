## Final recommendation stack

Keep Python/FastAPI/AnyIO and scoped admission, queue, execution and batch services. Maintain small routes/modules with explicit ownership. Use Starlette's supported body middleware and small `input_limits`/`image_input` services for resource policy. Keep URL policy and transport in `remote_url`/`remote_fetch`. Native tensor libraries already perform expensive inference; a Rust prototype requires measured end-to-end benefit and matching model/API/backend contracts. All future JavaScript should use ES Modules; locally adopted checkout and setup-python actions are ESM.

Use CPU-only Torch for the default image, cu130 Torch/NVIDIA CUDA 13 for modern NVIDIA GPUs, the documented cu126 profile for older amd64 NVIDIA hardware, and matching OpenVINO bindings/base for Intel deployments. Keep exact native-backend profiles separate from shared requirements and resolve Torch from a single official index before constrained PyPI installation. Keep non-root runtime execution and writable caches scoped to the application.

Validate with event-controlled worker tests, actual tiny native-model checks, network-disabled service smokes, and strict installed-package audits. Publish only from release tags after unit/backend gates. Immutable base/action image references require reviewed updates; default Docker bases receive weekly Dependabot proposals, while the legacy base override and direct scanner image require explicit digest review.

Keep the selected 16 MiB HTTP, 10 MiB compressed-image, 32 MiB batch-byte, 16-million source/resize-pixel, and 32-million aggregate-pixel defaults. Apply inline checks before admission and remote/direct-call checks in the worker. Keep Pillow's global safety policy intact and close detached images after native work. These choices add predictable input boundaries while preserving accepted-image math; they require explicit tuning for large batches and deployment memory limits.

Use only approved public numeric addresses for remote connections, verified original-host TLS identity, at most three validated redirects and four interleaved approved-address attempts before connection success. Refuse ambiguous authorities, credentials, mixed/empty unsafe DNS and HTTPS downgrades. Bound final decoded bodies and close responses/pools; avoid ambient proxy/netrc/CA overrides. Preserve authentication, default-disabled access, 400 policy/413 limit/500 download statuses and sanitized ordered batch failures. Next add aggregate ingress limits and production-model/cache contracts.

## Delivery outcome

The current remote-destination iteration preserves the previously merged execution/admission/input/backend work. The complete suite passed **412 tests** on Python 3.12 with pytest-cov 7.1.0; final focused validation passed 126 tests. Coverage is **94.61% lines and 88.69% branches**, above the unchanged 89.42%/79.37% floor. Input accounting and the executor retain 100% line/branch coverage. Strict OSV audits checked the actual CPU runtime's **56 packages** and QA environment's **67 packages** with zero known vulnerabilities and zero skips; no advisory suppression was used.

The newly rebuilt CPU image passed its shipped-script smoke with a real native CLIP projection, non-root/cache checks, authentication, startup and shutdown. Remote tests exercise real TLS with ephemeral certificates, original-host SNI/certificate/Host checks, recorded approved-IP connections, DNS changes, redirects, streaming/decompression limits and deterministic closure. A fresh independent read-only reviewer established no protected-address bypass and found two compatibility issues; final regressions verify restored download-error statuses/sanitized logs and address-family interleaving. The reviewer independently observed 20 undrained sockets close with unchanged descriptor count.

Ruff on the new files, scoped Pyright for changed service modules, workflow lint, compilation, copyright, coverage ratchet and whitespace checks passed. PR 49's exact ESM setup/cache-save bundles passed Node 24 syntax checks and executed locally with an isolated Python 3.12 tool-cache fixture; both workflow inputs/pins match the official metadata. Hosted cache and runner execution remain untested locally. GitHub MCP reconfirmed PR 49 remains open/unmerged.

The prior [backend iteration](backend-build-recommendation.md) separately records five-image smokes/audits and the RTX 5070 Ti check; those profiles were not all rebuilt in this remote-destination iteration. Historical input-budget results remain in their own record. CUDA ARM's unsupported vendor SBSA metadata remains deferred with pip check kept strict. No comparative Rust benchmark or production-weight/CDN fetch is claimed.
