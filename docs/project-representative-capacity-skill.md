# Representative capacity AI skill extension

## Design

Extend the existing capacity-calibration skill with a conditional workload
reference instead of creating an overlapping benchmark skill. This iteration
applies the skill-creator guidance: a narrow trigger, progressive disclosure,
reuse of executable repository probes and a focused behavioral evaluation.

The reference turns the operator's poster/landscape PNG/JPEG/WebP preference
into documented synthetic profiles. It requires encoded-byte references,
bounded subprocess ownership, observed server receipt and separate client,
model-owner and cgroup accounting. It preserves direct Docker publishing,
Python, production limits and the user's delivery authorization. It grants no
additional authority to publish, change production or modify upstream PRs.

## Outcome

The seven routing/evidence cases are evaluated against the implementation and
validation: unknown dimensions stay synthetic; lossy fixtures use encoded
references; timeout/output overflow/launch cancellation reap the child; process
high-water and cgroup peaks remain separate; incorrect or refused requests fail;
loopback does not establish external-address preservation; unrelated edits do
not require workload runs. Native regressions execute child failures and vector
rejection, and the actual model experiments exercise the selected profiles/codecs.
The repeated CPU two-caller maximum-batch failure demonstrates the refusal rule:
the 504 is retained as failed evidence with settled ownership, while one-caller
full-size and two-caller smaller-batch experiments are separate passing records.

The skill metadata validator passes. Full locked QA passes 1,112 tests with seven
existing skips, including 26 new fixture, IPC, receipt, vector, deadline and
cleanup regressions. Actual production models pass CPU one-caller full-size,
CPU two-caller smaller-batch and OpenVINO two-caller full-size experiments;
the CPU full-size two-caller refusal remains explicit failed evidence.
This is an instruction/evidence evaluation, not an independent agent benchmark.
