# Total upload and remote input lifetimes

Assessment: October 3, 2026. Baseline: `8f57c727c7f8efbcaf72c27df716bffc5e4eb16c`. Python is retained; delivery uses master and Unreleased changes without a release.

## Design and recommendations

The current complete-request admission gate bounds owners but a stalled upload can retain a slot indefinitely. Socket timeouts likewise do not bound synchronous DNS, all redirect/address attempts or a trickled HTTP response. Preserve existing byte/pixel/destination/TLS contracts and add independent total input budgets.

Use a small ASGI body-deadline middleware inside ingress admission and outside SlowAPI/body parsing. Start a monotonic 30-second budget at admitted dispatch; stop it when the complete body, disconnect or response start is observed. On expiry cancel downstream cooperative work, await its cleanup, send JSON 408 with HTTP/1 connection closure, and release ingress only after the response completes. This budget covers gaps between receives; it is not reset by each chunk. Complete-body inference retains its separate 45-second HTTP deadline and native execution owner.

Remote images use a fresh isolated Python interpreter per fetch with a parent-owned monotonic 15-second budget covering startup, URL/DNS checks, approved numeric connection attempts, TLS, redirect validation and the complete decoded body. Do not reuse a Python worker forked from a tensor-loaded parent; subprocess launch executes a fresh interpreter and imports neither Torch nor Transformers. OS-level fork/exec mechanics are platform dependent. Send only bounded URL/fetch options through stdin, strip ambient credentials and Python/proxy/CA override variables, and keep child stdout in an anonymous temporary file rather than an unbounded parent pipe buffer. Decode only a bounded success/error protocol with explicit safe error messages. Kill and reap a timed-out child before returning to the inference owner; do not abandon threads or release its slot while the child remains alive. Ordinary OS process creation/reaping and cooperative ASGI cleanup can add latency; these are not hard real-time guarantees.

Keep direct validated transport in its existing small module; production embedding calls the supervised adapter. Pure transport fakes explicitly exercise the child's direct transport semantics, while separate native process/network tests cover the production adapter. Remote URLs remain disabled by default. URL text is bounded to 8192 characters and the request protocol to 64 KiB; bytes retain the configured image ceiling. Batch remote fetches remain sequential, each independently bounded, and detached inference accounting remains unchanged.

## Alternatives and tradeoffs

| Choice | Pros | Cons | Decision |
|---|---|---|---|
| Socket/urllib3 total timeout alone | Minimal changes | Does not bound DNS or repeated socket reads | Reject as a complete lifetime limit |
| Return early from an abandoned fetch thread | Fast HTTP timeout | Blocking worker/resource can survive and accumulate | Reject |
| Replace the whole synchronous transport with async DNS/HTTP | Async cancellation; connection reuse | Broad security/API/backend rewrite; resolver cooperation still needs proof | Separate measured design |
| Cooperative upload scope plus disposable fetch subprocess | Preserves transport policy; terminates stuck DNS/network work; explicit ownership | Per-fetch startup/RSS cost; kill/reap and container PID sizing | Implement and measure |

## Official October 2026 research

Sources were discovered through web MCP. Current [urllib3 timeout documentation](https://urllib3.readthedocs.io/en/stable/reference/urllib3.util.html) describes DNS and trickled-read limits. Python [subprocess guidance](https://docs.python.org/3/library/subprocess.html?highlight=universal_newlines) requires killing and completing communication after timeout, notes buffering, and distinguishes process creation latency. [AnyIO cancellation](https://anyio.readthedocs.io/en/latest/cancellation.html) describes cooperative scopes and the inability to forcibly kill threads. [Starlette ASGI middleware](https://starlette.dev/middleware/) defines receive/send interception; [Uvicorn flow control](https://www.uvicorn.org/server-behavior/) explains response completion and request-body buffering. Python [async deadlines](https://docs.python.org/3.12/library/asyncio-task.html) likewise require cancellation cleanup before returning.

Python's [isolated command-line mode](https://docs.python.org/3.12/using/cmdline.html) excludes ambient Python variables, the current directory and user site packages. Only the trusted application package root is explicitly added. Docker's [service reference](https://docs.docker.com/reference/compose-file/services/) documents init/reaping and PID limits; calibrate native thread/process needs before setting a deployment PID ceiling. The process has the service UID, network, mounts and cgroup; this is a termination boundary, not a sandbox for hostile code. Temporary image bytes use private auto-deleted storage; provision its capacity and retain supervisor hard-stop policy.

Linux [getrusage](https://www.man7.org/linux/man-pages/man2/getrusage.2.html) preserves resource metrics across exec. The [kernel proc reference](https://docs.kernel.org/filesystems/proc.html?highlight=memavailable) defines RSS and high-water fields. The first full run incorrectly treated the inherited rusage high-water mark as fresh-child memory; the corrected probe records `/proc/self/status` RSS/high-water and preserves the rusage value separately. These coarse samples are operational evidence, not an exact allocation quota.

## Outcome

Production embedding now calls `remote_process`; `remote_fetch` remains the direct validated transport invoked by `remote_worker`. The bounded `remote_protocol` carries only fetch options and reviewed errors. No SDK graph, endpoint success schema or inference admission contract changes. Socket/upload/fetch durations reject zero, negative, boolean and nonfinite values; fractional durations and environment-over-TOML-over-default precedence are tested. The setup template and shipped config expose both new budgets.

Full locked Linux QA passes **832 tests**, with seven existing platform/optional skips. The **74 new cases** cover total upload gaps, downstream cleanup/408 ownership, non-HTTP bypass, completed body/response behavior, external cancellation, constructor/TOML/environment validation, bounded/malformed protocol, launch failure, startup time, kill/communication failure cleanup, blocked DNS, detached owners, native trickled headers/body, redirects, stalled TLS, trusted/invalid TLS and byte-error preservation. Windows Python 3.14.5 with pytest 9.1.1 passes **41 process/network cases** in temporary tooling; Linux CPython 3.12 remains the deployed contract. Coverage is **94.65% lines / 89.34% branches**, above unchanged **89.42% / 79.37%** floors. Exact QA inventory still verifies **67 hashed wheels**.

Native non-root probes in the existing locked CPU, OpenVINO and CUDA images load Torch and a small tensor in the parent, then exercise seven supervised and seven direct three-byte HTTP fetches. Median supervised latency is **365.30 / 365.26 / 315.23 ms**, versus **1.07 / 1.20 / 1.14 ms** direct. Last-sample child RSS is **28.52 / 28.30 / 30.24 MiB**; rusage values retain much larger parent history. A 0.7-second blocked-DNS budget returns in **0.7021 / 0.7022 / 0.7029 seconds**, with children terminated/reaped and pipes closed. Unmodified production workers reject private destinations in all three images. These final concurrent local probes ran alongside QA/CodeQL; an earlier lighter run measured roughly 265 ms medians. The observations establish overhead and loader/ownership behavior, not production-weight inference, accelerator capacity or every address-fallback timing. Native HTTP/TLS tests map only an approved numeric test destination to a loopback server; production has no such mapping.

Native CodeQL Python security-extended reports only the two existing contextual setup alerts (explicit `--show-key` and readable nonsecret defaults), with no new lifetime/transport alerts and no suppressions. Ruff, scoped Pyright, copyright, coverage, secret and whitespace checks accompany the [validation archive](validation/request-lifetimes-2026-10-03.json). PR 52 is documented separately in its [local adoption record](pr-52-local-validation.md).

The budgets stop network work but cannot forcibly interrupt synchronous Python running on the ASGI event loop, OS process creation/reaping or stuck native inference. Keep proxy/server and supervisor budgets aligned; owners remain held until actual cleanup. Sequential batches permit up to the configured number of per-image budgets after the HTTP caller detaches. Response start disables the upload timer, leaving send/backpressure separately unbounded. **Next implement a response-send lifetime with real Uvicorn slow-reader/disconnect tests**, preserving owner cleanup and avoiding a second response after headers. Then consider a shared remote batch budget and calibrate target PID, temporary storage and accelerator/concurrent-input capacity. Recommend the measured disposable worker now; defer pooling or an async transport replacement until profiling justifies its broader trust/lifetime design.
