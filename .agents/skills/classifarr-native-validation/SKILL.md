# Classifarr Native Validation

Establish which claim needs a real OS resource before selecting tests. Linux, mocked handles and in-process ASGI clients cannot prove Windows DACLs, child reaping or Proactor socket closure. Start at the repository root containing `OPENAI.md`; read it and the affected design record. Use [the native validation map](references/native-evidence.md) for commands and boundaries.

Use the smallest reviewed graph that exercises the changed contract. Windows contract profiles deliberately omit model runtimes. Their tests cover real ACLs, controlled child processes and sockets; they do not validate Windows production inference. Preserve actual private-destination rejection, host TLS identity, cleanup-before-capacity-release and shared batch budgets. Never substitute a fake or weaken destination policy to obtain a native pass.

Install the selected target's complete wheel/hash lock in a fresh venv using the reviewed bootstrap, isolated binary/no-index installation, pip check and exact inventory. Verify OS, architecture and conventional CPython minor; do not reuse Linux locks as a Windows environment or accept extra ambient packages. Check input attestations first. Discover official source URLs with available search/fetch tools when evaluating platform changes; separate official behavior from project choices.

For recurring Windows claims, run `scripts/validate_windows_contracts.py` rather than a hand-picked subset. It requires successful execution of ACL/junction, remote cancellation/reaping, shared batch and both HTTP parser cases. Inspect its metadata and exit code. Expected POSIX/symlink-privilege skips and uvloop deselections are explicit; a missing critical case or unexpected skip is a failure. Unit tests of this gate supplement actual native runs. Do not disable assertions, change timeouts to hide failures or infer resource settlement from cancellation alone.

Use temporary checkout-equivalent source/artifact directories excluding ignored `.env`, caches and private files. Keep logs, generated keys and certificates out of committed evidence and hosted artifacts. Record interpreter/OS/runner image, exact packages, source identities, fixed command, outcomes, skip/deselection accounting and unresolved limits. Local Windows 11 evidence does not establish hosted Server 2025 execution; a passing transport fixture does not establish client receipt or accelerator behavior.

Run affected Linux regressions when shared lock services or runtime contracts change. Keep existing security/scanner and coverage policy intact, and record contextual findings without suppressions. Update the separate design/outcome MD, Unreleased and next recommendation with observed results. Preserve the user's branch, commit/push and release choices; this skill grants no external-write authority and introduces no approval requirement.
